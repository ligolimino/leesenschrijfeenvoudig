# Letterlab zonder geluid of afbeeldingen

Dit is de sobere versie van het Letterlab. Dictee en klik-klak bevatten geen
geluidsbediening. In het dictee verschijnen geen afbeeldingen. De lesgever
kan nog steeds woorden, ontbrekende letters en klik-klakstroken instellen.

## Naast de volledige versie op GitHub zetten

Upload de **inhoud** van deze map in een nieuwe map `zonder-media` in dezelfde
repository. Laat de volledige versie in de hoofdmap staan. De beheerpagina
van deze variant staat daarna op `.../zonder-media/beheer/`; de gegenereerde
links verwijzen naar `.../zonder-media/dictee/` of
`.../zonder-media/klikklak/`. Bestaande links van de volledige versie blijven
werken.

De bestanden in `assets/fonts/` horen erbij: daarmee wordt Andika geladen.
Er zijn geen MP3's of afbeeldingsbestanden nodig. De woorden en instellingen
worden in de oefenlink bewaard. Een bestaande oefenlink kun je dus blijven
gebruiken zonder dat de lesgever zijn browser open moet houden.

**Let op:** uploaden in de hoofdmap zou de bestaande volledige versie
overschrijven. GitHub verwijdert daarbij de oude audiobestanden niet vanzelf.
